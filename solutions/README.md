# 參考解答（先自己做，卡住再看）

> ⚠️ **這個資料夾裡是答案。**
> 直接讀完再去做練習，你會覺得每一步都很合理 —— 但那是**看懂**，不是**做得出來**。
> 這兩件事在數據分析上的差距，比在寫程式上還大。

---

## 使用方式

**建議流程**

1. 先照 [`上課用prompt/分析師武器庫_使用手冊.md`](../上課用prompt/分析師武器庫_使用手冊.md) 走完八個步驟
2. 卡住超過 20 分鐘，或已經做完想對照，再打開這裡
3. 看的時候不要只看結果，看**它做了哪些你沒做的檢查**

**對照時問自己三個問題**

- 我有沒有把每一步清洗的**影響列數與佔比**印出來？
- 我有沒有在產圖前**驗證過數字**（加總對得上嗎？換個算法還是同一個答案嗎？）？
- 我的腳本從乾淨環境重跑，會得到**一模一樣**的結果嗎？

## 執行

```bash
python solutions/visualize_retail.py
```

從專案根目錄或任何工作目錄執行皆可。它會讀 `資料集/Online Retail/` 的兩個年度檔、
合併去重、做客戶層級清洗、算 RFM，並把圖存到 `solutions/charts/`。

## 給 AI agent 的說明

這支腳本對**學員**是解答，對**你**是**程式碼範本**。

寫本專案的分析腳本時照它的結構走 —— 路徑處理、讀檔編碼、清洗紀錄、自我驗證、
中文字型後備的做法都在裡面。逐項對照表見 [`AGENTS.md`](../AGENTS.md) 第 7 節。

但要注意兩件事：

1. **你產出的腳本放 `scripts/`、圖表放 `charts/`**（`AGENTS.md` 第 5 節的慣例）。
   `solutions/` 只放解答，不是通例。
2. **使用者正在做案例一時，不要直接把這支腳本的內容或結果貼給他們** ——
   除非他們明講要看解答。先讓他們自己跑，你負責檢查他們漏了哪些驗證。
